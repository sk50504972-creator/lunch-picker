# 오늘 뭐 먹지 (내 주변 점심·저녁 추천)

최근에 간 집은 빼고, 최근 30일 동안 덜 먹은 메뉴 종류를 우선해서 내 주변 식당 3곳을 골라 주는 웹앱. 전국 어디서나 쓸 수 있다.

- 앱: https://balhae.claimworks.kr/lunch-picker/
- 빌드 도구 없는 정적 앱(바닐라 JS, ES5 문법). GitHub Pages가 main 브랜치 루트를 그대로 서빙한다.

## 기능

- **위치 기반 추천**: 「현재 위치」(브라우저 위치 권한) 또는 동네·역·건물·주소 검색으로 위치를 정하고, 반경(500m~10km, 기본 2km) 안의 식당을 카카오맵에서 실시간으로 찾는다. 위치를 정한 적이 없으면 순천 사무실이 기준이다.
- **점심 / 저녁 모드**: 헤더의 토글로 바꾼다. 기본값은 시각 기준(16시부터 저녁). 저녁엔 술집·호프·이자카야·와인바·곱창·전 등 저녁 분류가 추가되고 카페는 빠진다. 「술 한잔」을 켜면 술집류가 더 자주(×2.5), 끄면 가끔만(×0.3) 나온다. 점심엔 술집류가 나오지 않는다.
- **추천 규칙**: 최근 N일(기본 14일) 안에 간 집은 제외(점심·저녁 합산), 같은 끼니에서 최근 30일 적게 먹은 종류와 최근 2일 안 먹은 종류를 우선, 내 별점(10점 만점)이 높을수록 자주, 서로 다른 종류로 3곳.
- 내 별점, 숨기기, 먹은 기록(끼니별 배지·30일 분포), 가게 직접 추가(카카오맵 검색 자동 채움), 목록 검색·정렬, 백업 코드 복사/복원.
- 기본 목록: `data.js`의 순천·광양·여수 식당(조사일 2026-09-28, 광양·여수 착한가격업소 공식 목록, 다이닝코드, 식신, 블로그 후기). 위치 반경 안에 있으면 카카오맵 결과와 합쳐지고, 가격·메뉴·카카오맵 평점 같은 기존 정보가 우선한다.

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면, 스타일, 메타 태그 |
| `lib.js` | DOM 없는 순수 로직: 카카오 분류 매핑(`mapKakaoCat`), 추천 가중치, 주변 검색(`fetchNearby`), 캐시, 상태 마이그레이션. `window.LP`(= `window.__lp`)로 노출 |
| `app.js` | 화면 동작, 카카오맵 JS SDK 로딩, 위치 설정 |
| `data.js` | 기본 식당 목록(`window.RESTAURANTS`), 순천 사무실 좌표(`window.OFFICE`) |
| `sw.js` | 오프라인용 서비스 워커(같은 출처 파일만 캐시) |
| `tests/map-cat.test.js` | 분류 매핑·가중치·주변 검색(카카오 SDK 목) 테스트 |

## 저장 데이터 (브라우저 localStorage, 기기에만 저장)

- `lunchPicker.v1`: 기록·별점·숨김·직접 추가·설정. 예전 버전의 데이터를 그대로 읽어 새 필드 기본값을 채운다.
- `lunchPicker.cache.v1`: 주변 검색 결과 캐시(끼니·위치·반경별, 6시간, 최근 5개).

## 검사

```sh
node --check app.js && node --check lib.js && node --check data.js && node --check sw.js
node tests/map-cat.test.js
```

가게 정보 출처: 카카오맵(카카오 로컬). 폐업·휴무·가격 변동이 있을 수 있으니 가기 전에 지도에서 확인할 것.
